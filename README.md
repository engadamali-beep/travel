# 📿 موقع أذكار الصباح والمساء

موقع عربي أنيق لأذكار الصباح والمساء بجميع الأحاديث الصحيحة بمصادرها.

🌐 **الموقع المباشر:** https://engadamali-beep.github.io/azkkkkar/

## المميزات

- ✅ أذكار الصباح والمساء بأحاديث صحيحة مع المصدر ورقم الحديث والفضل
- ✅ خط الرقعة (Aref Ruqaa) للعناوين وخط أميري للنصوص القرآنية
- ✅ تكبير وتصغير حجم الخط مع الحفظ
- ✅ مسبحة إلكترونية (33 / 100 / 1000 / مخصص) مع حفظ المجموع
- ✅ وضع ليلي / نهاري + شريط تقدم + بحث
- ✅ يعمل بدون إنترنت بعد أول تحميل (عدا الخطوط)

## النشر على GitHub Pages

الموقع ملف واحد `index.html` — يُنشر مباشرة من فرع `main` مجلد `root`.
